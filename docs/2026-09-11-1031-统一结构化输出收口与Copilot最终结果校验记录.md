# 统一结构化输出收口与 Copilot 最终结果校验记录

## 目标

统一 NovWr 中需要结构化结果的 LLM 调用，避免模型返回语法错误、字段类型错误或截断 JSON 时仍被当成成功结果保存。重点覆盖 Copilot 的工具循环自然结束、预算耗尽收束和单次调用兜底三个最终出口，同时保持普通聊天、中间工具调用和已有业务建议校验的行为。

## 实现边界

- `app/core/json_completion.py` 继续负责供应商的 `json_object` / `json_schema` 协议协商。
- `app/core/structured_output.py` 统一负责 JSON 文档解析、重复字段与非法数字拒绝、Pydantic 校验、截断识别、有限重试和脱敏日志。
- `app/core/copilot/final_response.py` 定义 Copilot 最终回答合同，并统一处理工具循环收束与单次调用。
- `AIClient.generate_structured()` 支持沿用已有消息上下文，不重新拼接或丢弃已收集的工具证据。
- 格式错误只触发有限的结构化修复；网络错误仍保留原有的有界请求重试，最终回答路径不额外叠加网络重试。
- `suggestions.py` 的事实引用、目标资源和审批边界继续由业务层校验，格式校验不会替代语义校验。

## 最终结果规则

1. 合法 JSON 且字段符合合同，直接保存。
2. 结果只是普通文本时，仅在普通聊天路径保留为 `answer`。
3. 结构化任务返回损坏 JSON、错误字段类型、重复字段、非法数字或空回答，进入有限 Schema 修复；修复仍失败则任务报错，不伪装为成功。
4. `finish_reason=length` 或 `content_filter` 不重复发送相同输出预算。
5. 修复请求使用已经读取的工具消息和证据，不重新执行全书搜索。
6. 失去 Run lease 时不继续调用模型，也不提交结果。

## 测试覆盖

- 真实 OpenAI SDK + MockTransport 验证 Schema 请求、供应商格式协商和 Pydantic 结果校验。
- 覆盖未转义引号、截断、重复键、非法数字、错误字段类型、空 choices、普通 Markdown 和 Unicode 内容。
- 覆盖工具循环自然结束、预算耗尽收束、工具不支持后的单次兜底。
- 覆盖修复时保留工具证据、旧世界数据不被修改、无效建议仍不能越过业务审批边界。
- 覆盖网络错误、超时、鉴权错误不被误判为格式错误；保留既有有界请求重试。
- 覆盖取消和 lease 丢失时释放并发槽位、不落盘错误结果。
